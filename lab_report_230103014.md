### Tile-size and cache analysis

The best tiled result used BS = 128 and achieved 0.099659 GFLOP/s. The nominal square-tile footprint, 3 × 128² × 8, is 393,216 bytes (384 KiB). It exceeds the reported 64 KiB L1 data cache and fits within the reported 4 MiB L2 capacity. Each worker handles 48 rows, so the active block at BS = 128 uses up to 224 KiB across the A, B, and C tiles. This also exceeds the reported L1 capacity and fits within the reported L2 capacity.

The naive version achieved the highest measured throughput at 0.118069 GFLOP/s. The best tiled result was about 15.6% lower. The naive inner loop accumulates into a local variable and writes each output element once. The reordered and tiled versions update the output buffer on every inner-loop iteration, and the tiled version adds block loops. Those implementation costs can offset the benefit of more contiguous memory access in Python.

# Phase 4 — Scheduling and Load Imbalance

## Method

Eight worker processes handled 12,000 items. The number of computation steps increased with the item index. Static block scheduling assigned each worker a contiguous range. Cyclic scheduling distributed items in round-robin order. Dynamic scheduling let workers claim the next chunk from a shared counter protected by a lock.

Each configuration was run once. Wall-clock time includes process startup and shutdown. The load imbalance factor λ is the longest worker time divided by the mean worker time. A value of 1.0 indicates equal worker times.

## Results

| Strategy | Chunk size | Wall time (ms) | Load imbalance λ |
|---|---:|---:|---:|
| Static block | — | 4734.7746 | 2.4536 |
| Cyclic | — | 2893.7150 | 1.0231 |
| Dynamic | 1 | 2849.6732 | 1.0052 |
| Dynamic | 4 | 2994.8975 | 1.0040 |
| Dynamic | 16 | 3005.4828 | 1.0144 |
| Dynamic | 64 | 3055.6292 | 1.0285 |
| Dynamic | 256 | 3244.7933 | 1.1120 |
| Dynamic | 1024 | 3685.0526 | 1.5689 |

## Analysis

Static block scheduling had the highest imbalance (λ = 2.4536). The first worker finished in 47.6097 ms, while the last worker took 4622.6993 ms because its range contained the most expensive items. Cyclic scheduling spread the expensive items across workers and reduced λ to 1.0231.

With dynamic scheduling, C = 1 required a lock acquisition for every item. This increased the number of synchronized claims but let workers keep taking work in small increments. It produced the shortest observed wall time, 2849.6732 ms, with λ = 1.0052. At C = 1024, workers made fewer synchronized claims, but large chunks near the end left some workers idle while others were still computing. Imbalance rose to 1.5689 and wall time was 29.31% higher than at C = 1.

The best observed dynamic chunk size was C = 1. It reduced wall time by 39.81% compared with static block scheduling and by 1.52% compared with cyclic scheduling. C = 4 had the lowest imbalance (λ = 1.0040), while C = 1 had the lowest wall time. Each configuration was measured once, so the small timing gap between C = 1 and cyclic scheduling may vary across runs.

## Verification

The verification hash uses the static block wall time (4734.7746 ms) and the best dynamic wall time (2849.6732 ms), in that order.

# Appendix — Python Source Code

## harness.py

```python
from dataclasses import dataclass
import multiprocessing as mp
import time
from typing import Callable


@dataclass
class BenchStats:
    min_ms: float
    median_ms: float
    iqr_ms: float
    max_ms: float


def fnv1a_hash(s: str) -> int:
    h = 14695981039346656037
    for b in s.encode("utf-8"):
        h ^= b
        h = (h * 1099511628211) & 0xFFFFFFFFFFFFFFFF
    return h


def run_benchmark(
    fn: Callable[[], None],
    warmup_runs: int = 3,
    timed_runs: int = 9,
) -> BenchStats:
    for _ in range(warmup_runs):
        fn()

    samples = []
    for _ in range(timed_runs):
        t0 = time.perf_counter_ns()
        fn()
        t1 = time.perf_counter_ns()
        samples.append((t1 - t0) / 1e6)

    samples.sort()
    mid = timed_runs // 2
    med = (
        samples[mid]
        if timed_runs % 2 == 1
        else 0.5 * (samples[mid - 1] + samples[mid])
    )
    q25 = samples[timed_runs // 4]
    q75 = samples[(3 * timed_runs) // 4]

    return BenchStats(samples[0], med, q75 - q25, samples[-1])


def emit_verify_tag(
    task_id: str,
    student_seed: int,
    primary_metric: float,
    secondary_metric: float,
) -> str:
    hw = mp.cpu_count()
    payload = (
        f"{task_id}|{student_seed}|{hw}|"
        f"{primary_metric:.4f}|{secondary_metric:.4f}"
    )
    sig = fnv1a_hash(payload)
    return f"VERIFY_HASH [{task_id}]: {sig:016X} (P_log={hw})"
```

## task1_falsesharing.py

```python
import ctypes
import multiprocessing as mp
from multiprocessing import shared_memory

from harness import emit_verify_tag, run_benchmark


STUDENT_ID = 230103014
TOTAL_ITERATIONS = 24_000_000


def fs_worker(shm_name, slot_idx, iterations):
    shm = shared_memory.SharedMemory(name=shm_name)
    cells = (ctypes.c_uint64 * 512).from_buffer(shm.buf)

    try:
        accumulator = cells[slot_idx]
        mask = 0xFFFFFFFFFFFFFFFF
        multiplier = 6364136223846793005

        for i in range(iterations):
            accumulator = (accumulator * multiplier + (i | 1)) & mask
            cells[slot_idx] = accumulator
    finally:
        del cells
        shm.close()


def measure(process_count, stride):
    shm = shared_memory.SharedMemory(create=True, size=4096)

    def trial():
        shm.buf[:4096] = bytes(4096)
        workers = [
            mp.Process(
                target=fs_worker,
                args=(shm.name, worker_id * stride, TOTAL_ITERATIONS // process_count),
            )
            for worker_id in range(process_count)
        ]

        for worker in workers:
            worker.start()
        for worker in workers:
            worker.join()

        if any(worker.exitcode != 0 for worker in workers):
            raise RuntimeError("A benchmark worker failed.")

    try:
        return run_benchmark(trial, warmup_runs=2, timed_runs=7)
    finally:
        shm.close()
        shm.unlink()


def main():
    physical_cores = 8
    process_counts = (1, 2, 4, 8)
    stride_medians = {}

    print("Table 1A - Stride sensitivity", flush=True)
    print("Stride | Distance (bytes) | Median (ms) | IQR (ms) | Mops/s", flush=True)

    for stride in (1, 2, 4, 8, 16, 32):
        stats = measure(physical_cores, stride)
        stride_medians[stride] = stats.median_ms
        throughput = TOTAL_ITERATIONS / (stats.median_ms * 1000)
        print(
            f"{stride} | {stride * 8} | {stats.median_ms:.4f} | "
            f"{stats.iqr_ms:.4f} | {throughput:.4f}",
            flush=True,
        )

    print("\nTable 1B - Process scaling", flush=True)
    print("Stride | Processes | Median (ms) | Speedup | Efficiency | Karp-Flatt", flush=True)

    for stride in (1, 16):
        for process_count in process_counts:
            median_ms = measure(process_count, stride).median_ms

            if process_count == 1:
                baseline_ms = median_ms
                karp_flatt = "N/A"
            else:
                inverse_p = 1 / process_count
                serial_fraction = (median_ms / baseline_ms - inverse_p) / (1 - inverse_p)
                karp_flatt = f"{serial_fraction:.4f}"

            speedup = baseline_ms / median_ms
            efficiency = speedup / process_count
            print(
                f"{stride} | {process_count} | {median_ms:.4f} | "
                f"{speedup:.4f} | {efficiency:.4f} | {karp_flatt}",
                flush=True,
            )

    print(emit_verify_tag("PHASE1", STUDENT_ID, stride_medians[1], stride_medians[16]))


if __name__ == "__main__":
    main()
```

## task2_scaling.py

```python
import math
import multiprocessing as mp
from statistics import median
from time import perf_counter_ns

from harness import emit_verify_tag, run_benchmark


STUDENT_ID = 230103014
STRONG_SIZE = 1_600_000
WEAK_SIZE_PER_WORKER = 250_000
TIMED_RUNS = 9


def serial_stage(size):
    total = 0.0
    for index in range(size // 20):
        value = (index % 1000) / 1000
        for _ in range(6):
            value = math.sqrt(1.0 + math.sin(value))
        total += value
    return total


def parallel_worker(bounds):
    start, stop = bounds
    total = 0.0
    for index in range(start, stop):
        value = (index % 1000) / 1000
        for _ in range(35):
            value = math.sin(value * 0.75 + 0.25)
        total += value
    return total


def measure(pool, process_count, size):
    chunks = [
        (worker * size // process_count, (worker + 1) * size // process_count)
        for worker in range(process_count)
    ]
    serial_times_ms = []

    def trial():
        start = perf_counter_ns()
        serial_stage(size)
        serial_times_ms.append((perf_counter_ns() - start) / 1e6)
        pool.map(parallel_worker, chunks, chunksize=1)

    stats = run_benchmark(trial, warmup_runs=3, timed_runs=TIMED_RUNS)
    return stats.median_ms, median(serial_times_ms[-TIMED_RUNS:])


def main():
    logical_cpus = mp.cpu_count()
    strong_results = []
    weak_results = []

    for process_count in range(1, logical_cpus + 1):
        print(f"Measuring p={process_count}/{logical_cpus}...", flush=True)
        with mp.Pool(processes=process_count) as pool:
            strong_results.append(measure(pool, process_count, STRONG_SIZE))
            weak_size = process_count * WEAK_SIZE_PER_WORKER
            weak_results.append(measure(pool, process_count, weak_size))

    strong_baseline, serial_baseline = strong_results[0]
    print("\nTable 2A - Strong scaling")
    print("Processes | Median (ms) | Stage A (ms) | Speedup | Efficiency")

    for p, (total_ms, serial_ms) in enumerate(strong_results, start=1):
        strong_speedup = strong_baseline / total_ms
        print(
            f"{p} | {total_ms:.4f} | {serial_ms:.4f} | "
            f"{strong_speedup:.4f} | {strong_speedup / p:.4f}"
        )

    weak_baseline = weak_results[0][0]
    print("\nTable 2B - Weak scaling")
    print("Processes | Elements | Median (ms) | Stage A (ms) | Efficiency | Gustafson")

    for p, (total_ms, serial_ms) in enumerate(weak_results, start=1):
        weak_efficiency = weak_baseline / total_ms
        alpha = serial_ms / total_ms
        gustafson_speedup = p - alpha * (p - 1)
        print(
            f"{p} | {p * WEAK_SIZE_PER_WORKER} | {total_ms:.4f} | "
            f"{serial_ms:.4f} | {weak_efficiency:.4f} | {gustafson_speedup:.4f}"
        )

    serial_fraction = serial_baseline / strong_baseline
    amdahl_max = 1 / serial_fraction
    amdahl_at_max_p = 1 / (
        serial_fraction + (1 - serial_fraction) / logical_cpus
    )

    print(f"\nMeasured serial fraction: {serial_fraction:.6f}")
    print(f"Amdahl theoretical maximum speedup: {amdahl_max:.4f}")
    print(f"Amdahl predicted speedup at p={logical_cpus}: {amdahl_at_max_p:.4f}")
    print(f"Observed strong speedup at p={logical_cpus}: {strong_speedup:.4f}")
    print(emit_verify_tag("PHASE2", STUDENT_ID, strong_speedup, gustafson_speedup))


if __name__ == "__main__":
    main()
```

```python
import multiprocessing as mp
from multiprocessing import shared_memory

from harness import run_benchmark


PHYSICAL_CORES = 8
BUFFER_BYTES = 96_000_000
COMPUTE_ITERATIONS = 2_500_000
FLOPS_PER_ITERATION = 32

source_memory = None
destination_memory = None


def attach_buffers(source_name, destination_name):
    global source_memory, destination_memory
    source_memory = shared_memory.SharedMemory(name=source_name)
    destination_memory = shared_memory.SharedMemory(name=destination_name)


def copy_worker(bounds):
    start, stop = bounds
    destination_memory.buf[start:stop] = source_memory.buf[start:stop]


def compute_worker(iterations):
    a = 0.999999
    b = 0.000001

    x0 = x1 = x2 = x3 = 0.1
    x4 = x5 = x6 = x7 = 0.2
    x8 = x9 = x10 = x11 = 0.3
    x12 = x13 = x14 = x15 = 0.4

    for _ in range(iterations):
        x0 = x0 * a + b
        x1 = x1 * a + b
        x2 = x2 * a + b
        x3 = x3 * a + b
        x4 = x4 * a + b
        x5 = x5 * a + b
        x6 = x6 * a + b
        x7 = x7 * a + b
        x8 = x8 * a + b
        x9 = x9 * a + b
        x10 = x10 * a + b
        x11 = x11 * a + b
        x12 = x12 * a + b
        x13 = x13 * a + b
        x14 = x14 * a + b
        x15 = x15 * a + b

    return x0 + x15


def measure_bandwidth():
    source = shared_memory.SharedMemory(create=True, size=BUFFER_BYTES)
    try:
        destination = shared_memory.SharedMemory(create=True, size=BUFFER_BYTES)
        try:
            block = b"\x01" * 1_000_000
            for start in range(0, BUFFER_BYTES, len(block)):
                source.buf[start:start + len(block)] = block

            chunks = [
                (
                    worker * BUFFER_BYTES // PHYSICAL_CORES,
                    (worker + 1) * BUFFER_BYTES // PHYSICAL_CORES,
                )
                for worker in range(PHYSICAL_CORES)
            ]

            with mp.Pool(
                processes=PHYSICAL_CORES,
                initializer=attach_buffers,
                initargs=(source.name, destination.name),
            ) as pool:
                stats = run_benchmark(
                    lambda: pool.map(copy_worker, chunks, chunksize=1),
                    warmup_runs=2,
                    timed_runs=7,
                )
            return stats.median_ms
        finally:
            destination.close()
            destination.unlink()
    finally:
        source.close()
        source.unlink()


def main():
    print(f"Physical cores used: {PHYSICAL_CORES}", flush=True)

    print("Measuring shared-memory copy bandwidth...", flush=True)
    copy_ms = measure_bandwidth()
    bandwidth_gbs = 2 * BUFFER_BYTES / (copy_ms * 1_000_000)
    print(f"Memory copy median: {copy_ms:.6f} ms", flush=True)
    print(f"Sustained bandwidth: {bandwidth_gbs:.6f} GB/s", flush=True)

    print("Measuring Python compute throughput...", flush=True)
    with mp.Pool(processes=PHYSICAL_CORES) as pool:
        stats = run_benchmark(
            lambda: pool.map(
                compute_worker,
                [COMPUTE_ITERATIONS] * PHYSICAL_CORES,
                chunksize=1,
            ),
            warmup_runs=2,
            timed_runs=7,
        )

    total_flops = PHYSICAL_CORES * COMPUTE_ITERATIONS * FLOPS_PER_ITERATION
    compute_gflops = total_flops / (stats.median_ms * 1_000_000)
    ridge_point = compute_gflops / bandwidth_gbs

    print(f"Compute median: {stats.median_ms:.6f} ms")
    print(f"Sustained Python compute: {compute_gflops:.6f} GFLOP/s")
    print(f"Ridge point: {ridge_point:.6f} FLOP/byte")


if __name__ == "__main__":
    main()
```

## task3b_gemm.py

```python
from array import array
from contextlib import ExitStack
import multiprocessing as mp
from multiprocessing import shared_memory

from harness import emit_verify_tag, run_benchmark


STUDENT_ID = 230103014
N = 384
WORKERS = 8
MATRIX_BYTES = N * N * 8
TILE_SIZES = (4, 8, 12, 16, 24, 32, 48, 64, 96, 128)


def attach_matrices(names):
    global worker_segments, matrix_a, matrix_b, matrix_c
    worker_segments = [shared_memory.SharedMemory(name=name) for name in names]
    matrix_a, matrix_b, matrix_c = [
        segment.buf[:MATRIX_BYTES].cast("d") for segment in worker_segments
    ]


def multiply_rows(job):
    variant, first_row, last_row, tile = job
    a, b, c = matrix_a, matrix_b, matrix_c

    if variant == "naive":
        for i in range(first_row, last_row):
            row = i * N
            for j in range(N):
                dot = 0.0
                for k in range(N):
                    dot += a[row + k] * b[k * N + j]
                c[row + j] = dot

    elif variant == "reordered":
        for i in range(first_row, last_row):
            row = i * N
            for k in range(N):
                a_ik = a[row + k]
                b_row = k * N
                for j in range(N):
                    c[row + j] += a_ik * b[b_row + j]

    else:
        for i_block in range(first_row, last_row, tile):
            for j_block in range(0, N, tile):
                for k_block in range(0, N, tile):
                    i_end = min(i_block + tile, last_row)
                    j_end = min(j_block + tile, N)
                    k_end = min(k_block + tile, N)

                    for i in range(i_block, i_end):
                        row = i * N
                        for k in range(k_block, k_end):
                            a_ik = a[row + k]
                            b_row = k * N
                            for j in range(j_block, j_end):
                                c[row + j] += a_ik * b[b_row + j]


def measure(pool, output, variant, tile=0):
    jobs = [
        (variant, worker * N // WORKERS, (worker + 1) * N // WORKERS, tile)
        for worker in range(WORKERS)
    ]
    zeros = bytes(MATRIX_BYTES)

    def trial():
        output.buf[:MATRIX_BYTES] = zeros
        pool.map(multiply_rows, jobs, chunksize=1)

    stats = run_benchmark(trial, warmup_runs=1, timed_runs=3)
    throughput = 2 * N**3 / (stats.median_ms * 1_000_000)
    return stats.median_ms, throughput


def read_matrix(segment):
    result = array("d")
    result.frombytes(bytes(segment.buf[:MATRIX_BYTES]))
    return result


def main():
    with ExitStack() as stack:
        segments = []
        for _ in range(3):
            segment = shared_memory.SharedMemory(create=True, size=MATRIX_BYTES)
            stack.callback(segment.unlink)
            stack.callback(segment.close)
            segments.append(segment)

        a, b, c = segments
        a.buf[:MATRIX_BYTES] = array(
            "d", ((i % 31 - 15) / 16 for i in range(N * N))
        ).tobytes()
        b.buf[:MATRIX_BYTES] = array(
            "d", ((i % 37 - 18) / 32 for i in range(N * N))
        ).tobytes()

        names = tuple(segment.name for segment in segments)
        with mp.Pool(WORKERS, initializer=attach_matrices, initargs=(names,)) as pool:
            print("Variant | BS | Median (ms) | GFLOP/s | Tile bytes | Max error", flush=True)

            naive_ms, naive_rate = measure(pool, c, "naive")
            print(f"Naive | - | {naive_ms:.6f} | {naive_rate:.6f} | - | -", flush=True)

            reordered_ms, reordered_rate = measure(pool, c, "reordered")
            reference = read_matrix(c)
            print(
                f"Reordered | - | {reordered_ms:.6f} | {reordered_rate:.6f} | - | -",
                flush=True,
            )

            tile_results = []
            for tile in TILE_SIZES:
                median_ms, rate = measure(pool, c, "tiled", tile)
                actual = read_matrix(c)
                error = max(abs(x - y) for x, y in zip(actual, reference))
                if error >= 1e-9:
                    raise RuntimeError(f"Tile size {tile} failed the numerical check.")

                tile_results.append((rate, tile))
                print(
                    f"Tiled | {tile} | {median_ms:.6f} | {rate:.6f} | "
                    f"{3 * tile**2 * 8} | {error:.3e}",
                    flush=True,
                )

    best_rate, best_tile = max(tile_results)
    print(f"\nBest tile size: {best_tile}")
    print(f"Best tiled throughput: {best_rate:.6f} GFLOP/s")
    print(emit_verify_tag("PHASE3", STUDENT_ID, naive_rate, best_rate))


if __name__ == "__main__":
    main()
```

## task4_scheduling.py

```python
import math
import multiprocessing as mp
from time import perf_counter_ns

from harness import emit_verify_tag


STUDENT_ID = 230103014
WORKERS = 8
ITEMS = 12_000
CHUNK_SIZES = (1, 4, 16, 64, 256, 1024)


def run_items(indices):
    for index in indices:
        iterations = 1 + (index * index) // 3600
        value = (index % 100) / 100

        for _ in range(iterations):
            value = math.sqrt(2.0 + math.sin(value) * math.cos(value))


def worker(worker_id, strategy, chunk_size, next_item, lock, worker_times):
    start_ns = perf_counter_ns()

    if strategy == "Static block":
        first = worker_id * ITEMS // WORKERS
        last = (worker_id + 1) * ITEMS // WORKERS
        run_items(range(first, last))
    elif strategy == "Cyclic":
        run_items(range(worker_id, ITEMS, WORKERS))
    else:
        while True:
            with lock:
                first = next_item.value
                if first >= ITEMS:
                    break
                last = min(first + chunk_size, ITEMS)
                next_item.value = last

            run_items(range(first, last))

    worker_times[worker_id] = (perf_counter_ns() - start_ns) / 1e6


def measure(strategy, chunk_size=0):
    worker_times = mp.Array("d", WORKERS, lock=False)
    next_item = mp.RawValue("i", 0)
    lock = mp.Lock()

    processes = [
        mp.Process(
            target=worker,
            args=(worker_id, strategy, chunk_size, next_item, lock, worker_times),
        )
        for worker_id in range(WORKERS)
    ]

    start_ns = perf_counter_ns()
    for process in processes:
        process.start()
    for process in processes:
        process.join()
    wall_ms = (perf_counter_ns() - start_ns) / 1e6

    if any(process.exitcode != 0 for process in processes):
        raise RuntimeError("A scheduling worker failed.")

    times = list(worker_times)
    imbalance = max(times) / (sum(times) / WORKERS)
    return wall_ms, imbalance, times


def print_result(strategy, chunk_size, result):
    wall_ms, imbalance, times = result
    chunk_label = str(chunk_size) if chunk_size else "-"
    print(f"{strategy} | {chunk_label} | {wall_ms:.4f} | {imbalance:.4f}")
    print("Worker times (ms): " + ", ".join(f"{time_ms:.4f}" for time_ms in times), flush=True)


def main():
    print("Strategy | Chunk size | Wall time (ms) | Imbalance", flush=True)

    static_result = measure("Static block")
    print_result("Static block", 0, static_result)

    cyclic_result = measure("Cyclic")
    print_result("Cyclic", 0, cyclic_result)

    dynamic_results = []
    for chunk_size in CHUNK_SIZES:
        result = measure("Dynamic", chunk_size)
        print_result("Dynamic", chunk_size, result)
        dynamic_results.append((result[0], chunk_size))

    best_wall_ms, best_chunk_size = min(dynamic_results)
    print(f"\nBest dynamic chunk size: {best_chunk_size}")
    print(f"Best dynamic wall time: {best_wall_ms:.4f} ms")
    print(emit_verify_tag("PHASE4", STUDENT_ID, static_result[0], best_wall_ms))


if __name__ == "__main__":
    main()
```
