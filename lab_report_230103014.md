## Phase 3 — Empirical Roofline and Matrix Multiplication

### Phase 3A — Measured Roofline

| Metric | Measured value |
|---|---:|
| Memory copy median | 3.020333 ms |
| Sustained memory bandwidth | 42.379433 GB/s |
| Compute median | 1539.868375 ms |
| Sustained Python compute throughput | 0.311715 GFLOP/s |
| Ridge point | 0.007355 FLOP/byte |

The bandwidth test copied 64 MB between two shared-memory buffers using eight workers. The bandwidth calculation counts 64 MB read and 64 MB written. Each compute worker performed 60 million floating-point operations, counting multiplication and addition separately. The ridge point is the measured compute throughput divided by the measured bandwidth.

### Phase 3B — GEMM and tile-size sweep

The benchmark multiplied 256 × 256 double-precision matrices using eight workers. Each configuration used two warm-up runs and seven timed runs. The timing included resetting the output matrix and dispatching tasks to the process pool. The numerical check ran after timing.

| Tiled | 96 | 519.032333 | 0.064648 | 221184 | 0 |
| Tiled | 128 | 517.027708 | 0.064899 | 393216 | 0 |

### Cache and Roofline analysis

The best tiled configuration used BS = 128 and achieved 0.064899 GFLOP/s. Its nominal square-tile footprint was 3 × 128² × 8 = 393,216 bytes (384 KiB). Each worker owned 32 rows, so its active A, B, and C blocks at BS = 128 had a combined footprint of up to 192 KiB. Both footprints exceed the reported 64 KiB L1 data cache and fit within the reported 4 MiB L2 capacity.

Naive was the fastest overall at 0.068568 GFLOP/s. The best tiled configuration had about 5.35% lower throughput. Naive accumulates each dot product in a local variable and writes each output element once. Reordered and Tiled update the output buffer on every inner-loop iteration. In Python, those repeated accesses and the extra block loops can offset the benefit of contiguous memory access.

The Roofline bound is min(0.311715, 42.379433 × I) GFLOP/s, where I is operational intensity in FLOP/byte. All three intensity estimates are above the measured ridge point, so the model assigns each variant the same compute ceiling.

| Variant | Estimated intensity (FLOP/byte) | Roofline bound (GFLOP/s) | Share of bound |
|---|---:|---:|---:|
| Naive | 0.1250 | 0.311715 | 22.00% |
| Reordered | 0.0833 | 0.311715 | 20.57% |
| Tiled, BS = 128 | 10.6667 | 0.311715 | 20.82% |

The naive estimate assumes two 8-byte operand reads for two FLOPs. The reordered estimate assumes one B read and one C read and write for two FLOPs, with A held in a local variable. The tiled estimate uses BS / 12 for a full square tile. These estimates describe the access patterns. Actual DRAM traffic was not measured for GEMM.

The verification hash uses the Naive throughput and the best Tiled throughput, in that order.

## Phase 4 — Scheduling and Load Imbalance

Eight worker processes handled 8,000 items. The work per item increased with its index according to K(i) = 1 + floor((i / 40)²). Static block scheduling assigned contiguous ranges. Cyclic scheduling assigned items in round-robin order. Dynamic scheduling let workers claim chunks from a synchronized shared counter.

Each configuration was measured once. Wall time includes process startup and shutdown. The load imbalance factor λ is the longest worker time divided by the mean worker time. Values closer to 1 indicate more evenly distributed worker times.

### Results

| Strategy | Chunk size | Wall time (ms) | Load imbalance λ |
|---|---:|---:|---:|
| Static block | — | 3648.2354 | 2.3892 |
| Cyclic | — | 2958.8614 | 1.0122 |
| Dynamic | 1 | 3405.4021 | 1.0039 |
| Dynamic | 8 | 3398.6741 | 1.0102 |
| Dynamic | 64 | 3629.5462 | 1.0634 |
| Dynamic | 512 | 4302.8127 | 1.4446 |

### Analysis

Static block scheduling had the highest imbalance (λ = 2.3892). The first worker took 46.6776 ms and the last took 3505.7792 ms because the last range contained the most expensive items. Cyclic scheduling spread expensive items across workers and achieved the shortest overall wall time (2958.8614 ms).

With dynamic scheduling, C = 1 required a synchronized claim for each item and gave the lowest imbalance (λ = 1.0039). At C = 512, workers made fewer synchronized claims. Larger chunks left some workers with substantially more work near the end. Imbalance increased to 1.4446, and wall time was 26.35% higher than at C = 1.

The fastest observed dynamic chunk size was C = 8. It was only 0.20% faster than C = 1 in this run. Since each configuration was measured once, that small gap could vary across runs.

The verification hash uses the static block wall time (3648.2354 ms) and the best dynamic wall time (3398.6741 ms), in that order.

## Appendix — Python Source Code

### `harness.py`

```python
from dataclasses import dataclass
import multiprocessing as mp
import time
from typing import Callable


@dataclass
class BenchStats:
    min_ms: float
    median_ms: float
    iqr_ms: float


def fnv1a_hash(s: str) -> int:
    h = 14695981039346656037
    for b in s.encode("utf-8"):
        h = ((h ^ b) * 1099511628211) & 0xFFFFFFFFFFFFFFFF
    return h


def run_benchmark(
    fn: Callable[[], None], warmup: int = 2, runs: int = 7
) -> BenchStats:
    for _ in range(warmup):
        fn()

    samples = []
    for _ in range(runs):
        t0 = time.perf_counter_ns()
        fn()
        samples.append((time.perf_counter_ns() - t0) / 1e6)

    samples.sort()
    med = samples[runs // 2]
    iqr = samples[(3 * runs) // 4] - samples[runs // 4]
    return BenchStats(samples[0], med, iqr)


def emit_verify_tag(phase: str, seed: int, m1: float, m2: float) -> str:
    hw = mp.cpu_count()
    sig = fnv1a_hash(f"{phase}|{seed}|{hw}|{m1:.4f}|{m2:.4f}")
    return f"VERIFY_HASH [{phase}]: {sig:016X} (P_log={hw})"
```

### `task1_falsesharing.py`

```python
import ctypes
import multiprocessing as mp
from multiprocessing import shared_memory

from harness import emit_verify_tag, run_benchmark


STUDENT_ID = 230103014
TOTAL_ITERATIONS = 16_000_000


def fs_worker(shm_name, slot_idx, iterations):
    shm = shared_memory.SharedMemory(name=shm_name)
    cells = (ctypes.c_uint64 * 512).from_buffer(shm.buf)

    try:
        accumulator = cells[slot_idx]
        mask = 0xFFFFFFFFFFFFFFFF
        multiplier = 6364136223846793005

        for i in range(iterations):
            accumulator = (accumulator * multiplier + (i | 1)) & mask
            cells[slot_idx] = accumulator
    finally:
        del cells
        shm.close()


def measure(process_count, stride):
    shm = shared_memory.SharedMemory(create=True, size=4096)

    def trial():
        shm.buf[:4096] = bytes(4096)
        workers = [
            mp.Process(
                target=fs_worker,
                args=(shm.name, worker_id * stride, TOTAL_ITERATIONS // process_count),
            )
            for worker_id in range(process_count)
        ]

        for worker in workers:
            worker.start()
        for worker in workers:
            worker.join()

        if any(worker.exitcode != 0 for worker in workers):
            raise RuntimeError("A benchmark worker failed.")

    try:
        return run_benchmark(trial, warmup=2, runs=7)
    finally:
        shm.close()
        shm.unlink()


def main():
    physical_cores = 8
    process_counts = (1, 2, 4, 8)
    stride_medians = {}

    print("Table 1A - Stride sensitivity", flush=True)
    print("Stride | Distance (bytes) | Median (ms) | IQR (ms) | Mops/s", flush=True)

    for stride in (1, 2, 4, 8, 16, 32):
        stats = measure(physical_cores, stride)
        stride_medians[stride] = stats.median_ms
        throughput = TOTAL_ITERATIONS / (stats.median_ms * 1000)
        print(
            f"{stride} | {stride * 8} | {stats.median_ms:.4f} | "
            f"{stats.iqr_ms:.4f} | {throughput:.4f}",
            flush=True,
        )

    print("\nTable 1B - Process scaling", flush=True)
    print("Stride | Processes | Median (ms) | Speedup | Efficiency | Karp-Flatt", flush=True)

    for stride in (1, 16):
        for process_count in process_counts:
            median_ms = measure(process_count, stride).median_ms

            if process_count == 1:
                baseline_ms = median_ms
                karp_flatt = "N/A"
            else:
                inverse_p = 1 / process_count
                serial_fraction = (median_ms / baseline_ms - inverse_p) / (1 - inverse_p)
                karp_flatt = f"{serial_fraction:.4f}"

            speedup = baseline_ms / median_ms
            efficiency = speedup / process_count
            print(
                f"{stride} | {process_count} | {median_ms:.4f} | "
                f"{speedup:.4f} | {efficiency:.4f} | {karp_flatt}",
                flush=True,
            )

    print(emit_verify_tag("PHASE1", STUDENT_ID, stride_medians[1], stride_medians[16]))


if __name__ == "__main__":
    main()
```

### `task2_scaling.py`

```python
import math
import multiprocessing as mp
from statistics import median
from time import perf_counter_ns

from harness import emit_verify_tag, run_benchmark


STUDENT_ID = 230103014
STRONG_SIZE = 1_200_000
WEAK_SIZE_PER_WORKER = 200_000
WARMUP_RUNS = 2
TIMED_RUNS = 7


def serial_stage(size):
    total = 0.0

    for index in range(size // 20):
        value = (index % 1000) / 1000
        for _ in range(5):
            value = math.sqrt(1.0 + math.sin(value))
        total += value

    return total


def parallel_worker(bounds):
    start, stop = bounds
    total = 0.0

    for index in range(start, stop):
        value = (index % 1000 + 1) / 1000
        for _ in range(30):
            value = math.sin(value)
        total += value

    return total


def measure(pool, process_count, size):
    chunks = [
        (worker * size // process_count, (worker + 1) * size // process_count)
        for worker in range(process_count)
    ]
    serial_times_ms = []

    def trial():
        start_ns = perf_counter_ns()
        serial_stage(size)
        serial_times_ms.append((perf_counter_ns() - start_ns) / 1e6)
        pool.map(parallel_worker, chunks, chunksize=1)

    stats = run_benchmark(trial, warmup=WARMUP_RUNS, runs=TIMED_RUNS)
    serial_median_ms = median(serial_times_ms[WARMUP_RUNS:])
    return stats.median_ms, serial_median_ms


def main():
    logical_cpus = mp.cpu_count()
    strong_results = []
    weak_results = []

    for process_count in range(1, logical_cpus + 1):
        print(f"Measuring p={process_count}/{logical_cpus}...", flush=True)
        weak_size = process_count * WEAK_SIZE_PER_WORKER

        with mp.Pool(processes=process_count) as pool:
            strong_results.append(measure(pool, process_count, STRONG_SIZE))
            weak_results.append(measure(pool, process_count, weak_size))

    strong_baseline_ms, serial_baseline_ms = strong_results[0]
    strong_speedups = []

    print("\nTable 2A - Strong scaling")
    print("Processes | Median (ms) | Stage A (ms) | Speedup | Efficiency")

    for p, (total_ms, serial_ms) in enumerate(strong_results, start=1):
        speedup = strong_baseline_ms / total_ms
        efficiency = speedup / p
        strong_speedups.append(speedup)
        print(
            f"{p} | {total_ms:.4f} | {serial_ms:.4f} | "
            f"{speedup:.4f} | {efficiency:.4f}"
        )

    weak_baseline_ms = weak_results[0][0]
    gustafson_speedups = []

    print("\nTable 2B - Weak scaling")
    print("Processes | Elements | Median (ms) | Stage A (ms) | Efficiency | Gustafson")

    for p, (total_ms, serial_ms) in enumerate(weak_results, start=1):
        efficiency = weak_baseline_ms / total_ms
        alpha = serial_ms / total_ms
        speedup = p - alpha * (p - 1)
        gustafson_speedups.append(speedup)
        print(
            f"{p} | {p * WEAK_SIZE_PER_WORKER} | {total_ms:.4f} | "
            f"{serial_ms:.4f} | {efficiency:.4f} | {speedup:.4f}"
        )

    serial_fraction = serial_baseline_ms / strong_baseline_ms
    amdahl_cap = 1 / serial_fraction
    amdahl_at_max_p = 1 / (
        serial_fraction + (1 - serial_fraction) / logical_cpus
    )
    observed_strong = strong_speedups[-1]
    observed_gustafson = gustafson_speedups[-1]

    print(f"\nMeasured serial fraction: {serial_fraction:.6f}")
    print(f"Amdahl theoretical maximum speedup: {amdahl_cap:.4f}")
    print(f"Amdahl predicted speedup at p={logical_cpus}: {amdahl_at_max_p:.4f}")
    print(f"Observed strong speedup at p={logical_cpus}: {observed_strong:.4f}")
    print(emit_verify_tag("PHASE2", STUDENT_ID, observed_strong, observed_gustafson))
```

```python
source_memory = None
destination_memory = None


def attach_buffers(source_name, destination_name):
    global source_memory, destination_memory
    source_memory = shared_memory.SharedMemory(name=source_name)
    destination_memory = shared_memory.SharedMemory(name=destination_name)


def copy_worker(bounds):
    start, stop = bounds
    destination_memory.buf[start:stop] = source_memory.buf[start:stop]


def compute_worker(iterations):
    a = 0.999999
    b = 0.000001

    x0 = x1 = x2 = x3 = 0.1
    x4 = x5 = x6 = x7 = 0.2
    x8 = x9 = x10 = x11 = 0.3
    x12 = x13 = x14 = x15 = 0.4

    for _ in range(iterations):
        x0 = x0 * a + b
        x1 = x1 * a + b
        x2 = x2 * a + b
        x3 = x3 * a + b
        x4 = x4 * a + b
        x5 = x5 * a + b
        x6 = x6 * a + b
        x7 = x7 * a + b
        x8 = x8 * a + b
        x9 = x9 * a + b
        x10 = x10 * a + b
        x11 = x11 * a + b
        x12 = x12 * a + b
        x13 = x13 * a + b
        x14 = x14 * a + b
        x15 = x15 * a + b

    return x0 + x15


def measure_bandwidth():
    source = shared_memory.SharedMemory(create=True, size=BUFFER_BYTES)
    try:
        destination = shared_memory.SharedMemory(create=True, size=BUFFER_BYTES)
        try:
            block = b"\x01" * 1_000_000
            for start in range(0, BUFFER_BYTES, len(block)):
                source.buf[start:start + len(block)] = block

            chunks = [
                (
                    worker * BUFFER_BYTES // PHYSICAL_CORES,
                    (worker + 1) * BUFFER_BYTES // PHYSICAL_CORES,
                )
                for worker in range(PHYSICAL_CORES)
            ]

            with mp.Pool(
                processes=PHYSICAL_CORES,
                initializer=attach_buffers,
                initargs=(source.name, destination.name),
            ) as pool:
                stats = run_benchmark(
                    lambda: pool.map(copy_worker, chunks, chunksize=1),
                    warmup=2,
                    runs=7,
                )
            return stats.median_ms
        finally:
            destination.close()
            destination.unlink()
    finally:
        source.close()
        source.unlink()


def run_roofline():
    print(f"Physical cores used: {PHYSICAL_CORES}", flush=True)

    print("Measuring shared-memory copy bandwidth...", flush=True)
    copy_ms = measure_bandwidth()
    bandwidth_gbs = 2 * BUFFER_BYTES / (copy_ms * 1_000_000)
    print(f"Memory copy median: {copy_ms:.6f} ms", flush=True)
    print(f"Sustained bandwidth: {bandwidth_gbs:.6f} GB/s", flush=True)

    print("Measuring Python compute throughput...", flush=True)
    with mp.Pool(processes=PHYSICAL_CORES) as pool:
        stats = run_benchmark(

                compute_worker,

    compute_gflops = total_flops / (stats.median_ms * 1_000_000)

    print(f"Compute median: {stats.median_ms:.6f} ms")
    print(f"Sustained Python compute: {compute_gflops:.6f} GFLOP/s")
    print(f"Ridge point: {ridge_point:.6f} FLOP/byte")

from array import array
from contextlib import ExitStack
import multiprocessing as mp
from multiprocessing import shared_memory

from harness import emit_verify_tag, run_benchmark


STUDENT_ID = 230103014
N = 256

MATRIX_BYTES = N * N * 8
TILE_SIZES = (8, 16, 32, 64, 96, 128)


def attach_matrices(names):
    global worker_segments, matrix_a, matrix_b, matrix_c
    worker_segments = [shared_memory.SharedMemory(name=name) for name in names]
    matrix_a, matrix_b, matrix_c = [
        segment.buf[:MATRIX_BYTES].cast("d") for segment in worker_segments
    ]


def multiply_rows(job):
    variant, first_row, last_row, tile = job
    a, b, c = matrix_a, matrix_b, matrix_c

    if variant == "naive":
        for i in range(first_row, last_row):
            row = i * N
            for j in range(N):
                dot = 0.0
                for k in range(N):
                    dot += a[row + k] * b[k * N + j]
                c[row + j] = dot

    elif variant == "reordered":
        for i in range(first_row, last_row):
            row = i * N
            for k in range(N):
                a_ik = a[row + k]
                b_row = k * N
                for j in range(N):
                    c[row + j] += a_ik * b[b_row + j]

    else:
        for i_block in range(first_row, last_row, tile):
            for j_block in range(0, N, tile):
                for k_block in range(0, N, tile):
                    i_end = min(i_block + tile, last_row)
                    j_end = min(j_block + tile, N)
                    k_end = min(k_block + tile, N)

                    for i in range(i_block, i_end):
                        row = i * N
                        for k in range(k_block, k_end):
                            a_ik = a[row + k]
                            b_row = k * N
                            for j in range(j_block, j_end):
                                c[row + j] += a_ik * b[b_row + j]


def measure(pool, output, variant, tile=0):
    jobs = [
        (variant, worker * N // WORKERS, (worker + 1) * N // WORKERS, tile)
        for worker in range(WORKERS)

    zeros = bytes(MATRIX_BYTES)

        output.buf[:MATRIX_BYTES] = zeros
        pool.map(multiply_rows, jobs, chunksize=1)

    stats = run_benchmark(trial)

        ).tobytes()
```

### `task4_scheduling.py`

```python
import math
import multiprocessing as mp
from time import perf_counter_ns

from harness import emit_verify_tag


STUDENT_ID = 230103014
WORKERS = 8
ITEMS = 8_000
CHUNK_SIZES = (1, 8, 64, 512)


def run_items(indices):
    for index in indices:
        iterations = 1 + (index * index) // 1600
        value = (index % 100) / 100

        for _ in range(iterations):
            value = math.sqrt(2.0 + math.sin(value) * math.cos(value))


def worker(worker_id, strategy, chunk_size, next_item, worker_times):
    start_ns = perf_counter_ns()

    if strategy == "Static block":
        first = worker_id * ITEMS // WORKERS
        last = (worker_id + 1) * ITEMS // WORKERS
        run_items(range(first, last))

    elif strategy == "Cyclic":
        run_items(range(worker_id, ITEMS, WORKERS))

    else:
        counter_lock = next_item.get_lock()
        counter = next_item.get_obj()

        while True:
            with counter_lock:
                first = counter.value
                if first >= ITEMS:
                    break
                last = min(first + chunk_size, ITEMS)
                counter.value = last

            run_items(range(first, last))

    worker_times[worker_id] = (perf_counter_ns() - start_ns) / 1e6


def measure(strategy, chunk_size=0):
    worker_times = mp.Array("d", WORKERS, lock=False)
    next_item = mp.Value("i", 0)

    processes = [
        mp.Process(
            target=worker,
            args=(worker_id, strategy, chunk_size, next_item, worker_times),
        )
        for worker_id in range(WORKERS)
    ]

    start_ns = perf_counter_ns()
    for process in processes:
        process.start()
    for process in processes:
        process.join()
    wall_ms = (perf_counter_ns() - start_ns) / 1e6

    if any(process.exitcode != 0 for process in processes):
        raise RuntimeError("A scheduling worker failed.")

    times = list(worker_times)
    mean_worker_ms = sum(times) / WORKERS
    imbalance = max(times) / mean_worker_ms
    return wall_ms, imbalance, times


def print_result(strategy, chunk_size, result):
    wall_ms, imbalance, times = result
    chunk_label = str(chunk_size) if chunk_size else "-"
    print(f"{strategy} | {chunk_label} | {wall_ms:.4f} | {imbalance:.4f}")
    worker_times_text = ", ".join(f"{time_ms:.4f}" for time_ms in times)
    print(f"Worker times (ms): {worker_times_text}", flush=True)


def main():
    print("Strategy | Chunk size | Wall time (ms) | Imbalance", flush=True)

    static_result = measure("Static block")
    print_result("Static block", 0, static_result)

    cyclic_result = measure("Cyclic")
    print_result("Cyclic", 0, cyclic_result)

    dynamic_results = []
    for chunk_size in CHUNK_SIZES:
        result = measure("Dynamic", chunk_size)
        print_result("Dynamic", chunk_size, result)
        dynamic_results.append((result[0], chunk_size))

    best_wall_ms, best_chunk_size = min(dynamic_results)
    print(f"\nBest dynamic chunk size: {best_chunk_size}")
    print(f"Best dynamic wall time: {best_wall_ms:.4f} ms")
    print(emit_verify_tag("PHASE4", STUDENT_ID, static_result[0], best_wall_ms))


if __name__ == "__main__":
    main()
```
